1. Le C a été créé en 1972. Il s'inspire du language B
2. Le BCPL est un language de programmation. Cela signifie Basic Combined Programming Language.
3. Oui, il existe plusieurs versions de C. La plus récente est la C23 qui date de 2024.
4. Unix est entièrement écrit en C.
5. On retrouve dans un programme C, une première partie de déclaration, puis le corps du programme.
6. Le préprocesseur est un outil qui analyse le code source avant qu'il soit traité par le compilateur.
7. Un makefile est un fichier texte de configuration qui permet d'automatiser la compilation d'un programme en C.
8. Les types de base du C sont les entiers int, les réels float et les caractères bool.
9. Une structure en C est un type de données personnalisé qui permet de regrouper des variables de types identiques ou différents.
10. Un pointeur est une variable qui contient l'adresse mémoire d'une autre variable.
11. Pour connaître la taille d'une variable, on utilise l'opérateur sizeof.
12. Il faut utiliser une technique de cast de pointeur ou byte-dump : on transforme le pointeur de l'entier en pointeur de caractères (unsigned char *).
13. Il faut stocker l'adresse de la variable dans un pointeur de type char.
14. Un tableau à une dimension est stocké de manière contiguë, soit les cases les unes derrière les autres en mémoire.
15. Un tableau à 2 dimensions est stocké en ordre ligne par ligne (row major order) : les lignes du tableau sont mises à plat et stockées de manière contiguë.
16. Les octets sont stockés en partant du plus petit poids vers le plus grand : le premier est le poids faible et le dernier et le poids fort.
17. String n'existe pas en C, on utilise un tableau de caractères char.
18. Oui, les chaines permettent de stocker de l'utf-8.
19. Un débogueur permet d'inspecter et d'analyser du code lors de son exécution afin de repérer les problèmes. Il existe GDB en C, et jdb en Java.
